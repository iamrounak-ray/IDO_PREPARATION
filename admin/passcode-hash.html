Make a new passcode

Type the passcode you want to give someone. This page works it out in your browser only; nothing is sent anywhere.

Document ID (copy all of it):

  1. Open your project in the Firebase console → Firestore Database.
  2. Click the codes collection → Add document.
  3. Paste the ID above into Document ID.
  4. Add one field, for example note (string) = who the passcode is for. Click Save.

The passcode then works once. After someone uses it, it can never be used again.
